# Shop Nest Cart App

This is a ReactJS application that fetches products from the Fake Store API and allows users to manage a shopping cart using a modal interface.

## Features

- **Product Display**: Fetches and displays products in a responsive grid layout.
- **Add to Cart**: Users can add products to the cart.
- **Duplicate Check**: Prevents duplicate items in the cart and displays an alert ("Item already added to the cart").
- **Cart Counter**: Real-time update of cart items count in the navigation bar.
- **Cart Modal**: A pop-up modal showing selected items.
- **Remove Items**: Ability to remove specific items directly from the modal.

## Tech Stack

- **ReactJS**: Component-based UI architecture.
- **Tailwind CSS (V4)**: For responsive and utility-first styling.
- **JavaScript**: For application logic and API integration.
- **Fake Store API**: Data source for products.

## How to Run

1. Clone the repository or copy the code.
2. Install dependencies (ensure `tailwindcss` is configured in vite.js).
   ```bash
   npm install
   ```
